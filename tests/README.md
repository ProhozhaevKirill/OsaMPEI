# Проверки редактора

Из корня проекта (PowerShell):

```powershell
venv\Scripts\python.exe web_tests/manage.py test create_tests --settings=web_tests.test_settings --noinput
```

Тесты используют отдельную SQLite в памяти. Проверяют создание и повторное открытие вопросов, несколько вариантов, длинные ответы, точки с запятой внутри ячеек, матрицы и откат при ошибке сохранения.

Откройте `tests/editor_regression.html` в Chrome для проверки настоящего MathLive. Внизу страницы должен появиться `PASS`. Проверяются клонирование полей, добавление вопросов и вариантов, сохранение матриц и запрет отправки незаполненных вариантов. Страница не отправляет данные на сервер.

Перед запуском обновлённого приложения примените миграцию расширения полей ответов:

```powershell
venv\Scripts\python.exe web_tests/manage.py migrate
```

Миграция 0036 переводит ответы, признаки правильности и погрешности в текстовые поля. Новые списки ответов хранятся в JSON с маркером `@answers:`, прежний формат продолжает читаться. Уже потерянные данные миграция не восстанавливает.
